使い方ガイド

このアプリについて

音声・動画ファイルをアップロードすると、自動で文字起こしをします。 動画は音声だけを取り出して処理します。結果は画面で確認でき、テキスト・Word・Excel・字幕として保存できます。

※ 文字起こしエンジンは Groq の Whisper。話し手を分けたいときは［話者分離して文字起こし］を選ぶと Gladia で処理し、「話者1」「話者2」を付けて書き起こします（無料枠は月10時間）。

使い方の流れ

  1. ログイン — 配布されたパスワードを入力します（「表示」ボタンで入力を確認できます）。
  2. ファイルを入れる — 枠にドラッグ＆ドロップ、またはクリックして選択。 マイク録音からそのまま起こすこともできます。
  3. 言語を選ぶ — 日本語／英語／他言語のボタンで選びます（既定は日本語）。 英語の音声は必ず「英語」を選ぶと、日本語に化けず英語のまま起こせます。「他言語」は自動判定です。
  4. （任意）語彙パックを選ぶ — 報道分野などの固有名詞リストを選ぶと表記精度が上がります。 迷ったら「選択しない」のままでOK。
  5. ボタンを押す — 「文字起こし開始」で通常どおり、「話者分離して文字起こし」なら話し手ごとに 「話者1」「話者2」を付けて起こします（無料枠は月10時間）。 「音声に変換 → 文字起こし」の進捗が出ます（長い音声は自動で分割）。
  6. 結果を確認 — 「TCの切り方」で表示の区切り（一文ごと〜段落ごと／TimeCodeなし）を選べます。
  7. 保存する — コピー、またはテキスト・Word・Excel・字幕で保存。 テキスト・Word・Excelは画面で選んだ切り方のまま保存されます。

対応しているファイル形式

音声

.mp3.m4a.wav .aac.flac.ogg .oga.opus.wma

動画（音声を自動抽出）

.mp4.mov.m4v .webm.mkv.avi .mpeg.mpg.3gp

アップロードの上限は既定で 300MB です。「大容量アップロード（R2）」が設定されていれば、 2〜3GBの大きな動画もそのままアップロードできます（大きいファイルは自動で分割アップロード）。 未設定の公開版では、とても大きい動画はローカル起動での利用がおすすめです。

大容量アップロード用のクラウド保存は無料枠が月10GBです。1本あたり最大3GBなので、 同じ日に何人もが大型の動画を上げると、上限に達して一時的にアップロードできなくなることがあります。 アップロードした動画は処理後に自動削除（＋1日で自動消去）されるので普段は問題ありませんが、 混み合いそうな日は時間をずらす・大きいファイルから先に処理すると安心です。

文章の「切り方」を選ぶ

結果画面の右上で選べます。テキスト・Word・Excelの保存にもそのまま反映されます。 「○秒ごと」も必ず文・句読点の切れ目で区切るので、文の途中では切れません。

切り方内容向いている用途
一文ごと文末（。！？など）に加え、息継ぎ（無音）や長さでも区切る。いちばん細かい。字幕・精密な編集
5秒ごと約5秒ごとに時間（TimeCode）を表示。細かい頭出し
10秒ごと（既定）約10秒ごとに時間を表示。標準的なバランス。標準
30秒ごと約30秒ごとに時間を表示。長い会議・講演
1分ごと約1分ごとに時間を表示。とても長い録音
段落ごと(息継ぎ)息継ぎ（無音の間）だけで段落分け。話し言葉の自然な区切り。先頭に時間。読みやすさ重視
段落ごと(文意)無音＋文末＋長さから文意の切れ目を推測して段落分け。先頭に時間。記事・議事録
TimeCodeなし時間表示なしの読みやすい本文（段落分け）。清書・配布

語彙パック（固有名詞の表記補正）

ファイルを入れたあとの確認画面で、言語ボタンの下から「語彙パック」を選べます。 報道分野などの固有名詞リストを選ぶと、その語を文字起こしエンジンに教えて、 人名・専門用語の表記精度が上がります。既定は「選択しない」で、選ばなくても文字起こしできます。

  • 「日本語」を選ぶと日本語の分野パック（政府・内閣・国会／外交・安全保障 など）、 「英語」を選ぶと英語のパックに切り替わります。「他言語」では語彙パックは出ません。
  • パックの語は時事用語のため、要人交代などに合わせて定期的な更新が必要です（管理者が更新します）。

文字起こしの精度と校正のおすすめ

このアプリは無料運用を最優先しているため、文字起こしの精度はお察し……。 固有名詞や専門用語、聞き取りにくい箇所は、どうしても間違いが残ります。 仕上げは、お手元のAI（ChatGPT・Claude・Gemini など）に貼り付けて校正することをおすすめします。

下のひな形をコピーし、文字起こし結果（テキスト）と一緒にAIへ渡すと、表記ゆれや変換ミスを直してくれます。 ※ AIは固有名詞を別の語に直してしまうことがあるので、最後は人の目で確認してください。

文字起こしの校正プロンプト（ひな形）

あなたは日本語の文字起こしの校正者です。以下の【文字起こし】を校正してください。

# やってよいこと
- 明らかな変換ミス・誤変換の修正
- 固有名詞（人名・組織名・地名・番組名など）や専門用語の表記の統一・修正
- 読点・句点の最小限の補い（読みやすさのため）

# やってはいけないこと
- 発言内容の言い換え・要約・意訳・追加・削除
- 語順や文体を変えること
- 話していない情報を補うこと

# 出力
- 校正後の本文だけを出力してください（説明や前置きは不要）。
- タイムスタンプ（[0:00] など）がある場合はそのまま残してください。
- 確信が持てない固有名詞は、変更せず末尾に「※要確認: ◯◯」と注記してください。

【固有名詞メモ（任意・あれば正しい表記を書く）】
（例：高市早苗、日本銀行、官房長官 …）

保存の形式

種類内容
テキスト(.txt)選んだ切り方の本文。「TimeCodeなし」なら時間なし、それ以外は [時:分:秒] 付き。
Word(.docx)選んだ切り方で、時間見出し＋本文。明朝体で整形（TimeCodeなしは見出しなし）。
Excel(.xlsx)「本文（選んだ切り方）」と「詳細（セグメント）」の2シート。列＝No／開始／終了／本文。
字幕(.srt)動画字幕用。切り方に関係なく、細かいセグメント単位の開始・終了時間つき。

仕組み（内部処理）

  1. ブラウザからファイルをサーバーへアップロード。
  2. サーバー内で ffmpeg が音声を 16kHz モノラルの軽い音声に変換（動画は音声のみ抽出）。
  3. 長い音声は約10分ごとに自動分割。
  4. 各部分を Groq Whisper に送って文字起こし → タイムスタンプを連結。
  5. 選んだ「切り方」に合わせて区切り、各まとまりの先頭にTimeCodeを付けて表示。

構成：Python + FastAPI（単一サーバー・ビルド不要）。ffmpeg はアプリに同梱。

料金（無料枠の目安）

Groq 無料枠：1時間あたり 音声およそ2時間分まで・1日 約2,000回まで無料。 ふだんの利用ならほぼ¥0です。

無料枠を使い切っても、有料は1時間あたり数円〜十数円程度と安価です（モデルにより変動）。

プライバシーとセキュリティ

  • アップロードしたファイルは一時フォルダで処理し、処理後に自動削除します（サーバーに残しません）。
  • 文字起こしのため、音声データは Groq のサーバー（クラウド）に送信されます。機密性の高い音声は、この点をご了承のうえご利用ください。
  • アプリは パスワードでログインする必要があります。利用しない人には知らせないでください。
  • このアプリが触れるのは「文字起こし機能」と画面表示用の画像だけです。 あなたのPC内のファイルにアクセスする機能はありません。

困ったとき

症状対処
「パスワードが違います」設定ファイル(.env)の APP_PASSWORD と入力を確認。
「GROQ_API_KEY が設定されていません」.env に Groq のキーを入れて起動し直す。
動画で「音声トラックが見つかりません」その動画に音声が含まれているか確認。
SSL / 通信エラーウイルス対策のHTTPS検査・VPN・プロキシ・不安定なWi‑Fiが原因のことが多い。自動で数回再試行します。
大容量アップロードが「ネットワークエラー」ウイルス対策のHTTPS検査・VPN・ブラウザ拡張が接続を切っていることが多い。シークレットウィンドウで開く／HTTPS検査を一時停止／別回線（テザリング等）で改善。自動でも粘って再試行します。
途中で止まる無料枠の上限に達した可能性。1時間ほど時間をおいてから再実行してください（短時間の制限なら自動で待機・再試行します）。

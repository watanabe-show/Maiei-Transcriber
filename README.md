# 🎙️ 音声文字起こし（Groq Whisper）

音声・動画ファイルをアップロードすると、自動で文字起こしするWebアプリです。
パスワード（合言葉）で複数人運用でき、運用コストはほぼ¥0です。

## できること

- 🎧 音声(mp3 / m4a / wav / aac / flac / ogg / opus など)の文字起こし
- 🎬 動画(mp4 / mov / webm / mkv / avi など)は**音声だけ自動抽出**して文字起こし
- ⏱️ タイムスタンプ付き表示・コピー・`.txt` / 時間つき`.txt` / 字幕`.srt` で保存
- 🎤 ブラウザのマイク録音 → そのまま文字起こし
- 🔑 合言葉によるログイン（複数人で共有可）
- 💾 長い音声は自動で10分ごとに分割して処理。アップロードファイルは処理後に自動削除

> ※ 話者分離（誰が話したか）はありません。タイムスタンプ付きの文字起こしです。

## 仕組み（ざっくり）

```
[ブラウザ] --ファイル--> [FastAPIサーバー]
                          ├ ffmpegで 16kHz mono mp3 に圧縮（動画は音声だけ抽出）
                          ├ 10分ごとに自動分割
                          └ Groq Whisper API で順番に文字起こし → タイムスタンプ連結
```

- フロント・バックともに1つのPythonサーバー（ビルド不要・npm不要）
- ffmpeg はWindowsでも手動インストール不要（`imageio-ffmpeg` 同梱バイナリを使用）

## 使い方A：自分のPCで動かす（ローカル / ¥0）

### 1. Groqの無料APIキーを取得
1. https://console.groq.com にアクセスして無料登録（クレジットカード不要）
2. 左メニュー **API Keys** → **Create API Key** → 表示されたキー（`gsk_...`）をコピー

### 2. 起動
1. この `transcriber` フォルダの中の **`run.bat` をダブルクリック**
2. 初回は自動で `.env`（設定ファイル）がメモ帳で開きます。次の2つを入力して保存:
   - `GROQ_API_KEY=` … さきほどのキーを貼り付け
   - `APP_PASSWORD=` … 好きな合言葉（例: `meeting2026`）
3. メモ帳を閉じる → 自動で必要なものをインストールし、ブラウザが開きます
4. 合言葉でログイン → ファイルをドラッグ＆ドロップ

> 同じWi-Fi内の別の人にも使ってもらうには、起動時に表示される
> `http://（あなたのPCのIPアドレス）:8000` を共有します（合言葉も伝えます）。

### 必要なもの
- Python 3.10 以上（未インストールなら https://www.python.org/downloads/ から。
  インストール時に「Add python.exe to PATH」にチェック）

## 使い方B：ネット上に公開する（Render無料枠）

1. この `transcriber` フォルダを **GitHub** のリポジトリに上げる
2. https://render.com に登録 → **New +** → **Blueprint** → 上げたリポジトリを選択
3. `render.yaml` が読み込まれるので、環境変数を設定:
   - `GROQ_API_KEY` … Groqのキー
   - `APP_PASSWORD` … ログインの合言葉
4. デプロイ完了後、表示されたURL（`https://xxx.onrender.com`）を共有

> 無料枠は一定時間アクセスが無いとスリープし、次回アクセス時に十数秒の起動待ちがあります。
> 大きい動画（数百MB）を扱う場合は、ローカル起動（使い方A）の方が安定します。

## 料金の目安（Groq）

- 無料枠：**1日2,000リクエスト / 音声 約2時間ぶん/時** ＝ 通常利用ならほぼ¥0
- 有料化しても `whisper-large-v3-turbo` で **約$0.04（≒¥6）/時間** と激安

## 設定（.env）

| 変数 | 説明 | 既定 |
|------|------|------|
| `GROQ_API_KEY` | GroqのAPIキー（必須） | （なし） |
| `APP_PASSWORD` | ログインの合言葉（必須） | `change-me` |
| `APP_PASSWORDS` | 複数の合言葉をカンマ区切りで許可 | （なし） |
| `SECRET_KEY` | セッション署名鍵（公開時は必ず設定） | 起動毎ランダム |
| `GROQ_MODEL` | `whisper-large-v3`（精度） / `-turbo`（高速） | `whisper-large-v3` |
| `DEFAULT_LANGUAGE` | `ja` / `en` / 空欄=自動 | `ja` |
| `MAX_UPLOAD_MB` | アップロード上限 | `300` |
| `CHUNK_SECONDS` | 分割の長さ（秒） | `600` |

## 困ったとき

- **「合言葉が違います」** → `.env` の `APP_PASSWORD` と入力を確認
- **「GROQ_API_KEY が設定されていません」** → `.env` にキーを入れて起動し直す
- **動画で「音声トラックが見つかりません」** → その動画に音声が含まれているか確認
- **文字起こしが途中で止まる** → 無料枠の制限に達した可能性。少し時間をおいて再実行（自動で待機・再試行もします）

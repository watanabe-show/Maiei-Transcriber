# 🎙️ 音声文字起こし（Groq Whisper）

音声・動画ファイルをアップロードすると、自動で文字起こしするWebアプリです。
パスワード（合言葉）で複数人運用でき、運用コストはほぼ¥0です。

## できること

- 🎧 音声(mp3 / m4a / wav / aac / flac / ogg / opus など)の文字起こし
- 🎬 動画(mp4 / mov / webm / mkv / avi など)は**音声だけ自動抽出**して文字起こし
- ⏱️ タイムスタンプ付き表示・コピー・`.txt` / 時間つき`.txt` / 字幕`.srt` で保存
- 🎤 ブラウザのマイク録音 → そのまま文字起こし
- 🔑 合言葉によるログイン（複数人で共有可）
- 💾 長い音声は自動で10分ごとに分割して処理。アップロードファイルは処理後に自動削除

> ※ 話者分離（誰が話したか）はありません。タイムスタンプ付きの文字起こしです。

## 仕組み（ざっくり）

```
[ブラウザ] --ファイル--> [FastAPIサーバー]
                          ├ ffmpegで 16kHz mono mp3 に圧縮（動画は音声だけ抽出）
                          ├ 10分ごとに自動分割
                          └ Groq Whisper API で順番に文字起こし → タイムスタンプ連結
```

- フロント・バックともに1つのPythonサーバー（ビルド不要・npm不要）
- ffmpeg はWindowsでも手動インストール不要（`imageio-ffmpeg` 同梱バイナリを使用）

## 使い方A：自分のPCで動かす（ローカル / ¥0）

### 1. Groqの無料APIキーを取得
1. https://console.groq.com にアクセスして無料登録（クレジットカード不要）
2. 左メニュー **API Keys** → **Create API Key** → 表示されたキー（`gsk_...`）をコピー

### 2. 起動
1. この `transcriber` フォルダの中の **`run.bat` をダブルクリック**
2. 初回は自動で `.env`（設定ファイル）がメモ帳で開きます。次の2つを入力して保存:
   - `GROQ_API_KEY=` … さきほどのキーを貼り付け
   - `APP_PASSWORD=` … 好きな合言葉（例: `meeting2026`）
3. メモ帳を閉じる → 自動で必要なものをインストールし、ブラウザが開きます
4. 合言葉でログイン → ファイルをドラッグ＆ドロップ

> 同じWi-Fi内の別の人にも使ってもらうには、起動時に表示される
> `http://（あなたのPCのIPアドレス）:8000` を共有します（合言葉も伝えます）。

### 必要なもの
- Python 3.10 以上（未インストールなら https://www.python.org/downloads/ から。
  インストール時に「Add python.exe to PATH」にチェック）

## 使い方B：ネット上に公開する（Render無料枠）

1. この `transcriber` フォルダを **GitHub** のリポジトリに上げる
2. https://render.com に登録 → **New +** → **Blueprint** → 上げたリポジトリを選択
3. `render.yaml` が読み込まれるので、環境変数を設定:
   - `GROQ_API_KEY` … Groqのキー
   - `APP_PASSWORD` … ログインの合言葉
4. デプロイ完了後、表示されたURL（`https://xxx.onrender.com`）を共有

> 無料枠は一定時間アクセスが無いとスリープし、次回アクセス時に十数秒の起動待ちがあります。
> 大きい動画は、下の「大容量動画（2〜3GB）に対応する」を設定すると公開版でも安定して扱えます。
> （未設定のままだと公開版のアップロード上限は数百MB程度。それ以上はローカル起動が安定）

### スリープを防ぐ（GitHub Actions keep-alive）

`.github/workflows/keep-alive.yml` を追加すると、指定した時間帯に GitHub Actions が5分ごとに
アプリへpingを送り、Render のスリープを防ぎます。

```yaml
on:
  schedule:
    - cron: '*/5 0-14 * * 0-5'  # 日〜金 9:00〜24:00 JST
```

曜日・時間帯は `cron` 式を書き換えてください（時刻は UTC。JST = UTC+9）。
GitHub Actions の無料枠（月2,000分）をほぼ消費しません（1回1秒未満）。

## 大容量動画（2〜3GB）に対応する（任意・Cloudflare R2）

公開版（使い方B）で**2〜3時間の動画**を扱いたい場合の設定です。設定すると、ブラウザから
**Renderサーバーを経由せずクラウドストレージ（R2）へ動画を直接アップロード**し、サーバーは
そこから音声だけを取り出して文字起こしします（Renderの無料枠ディスク/メモリを圧迫しません）。
**未設定なら何も変わりません**（この機能は完全に任意）。

> R2 は Cloudflare のストレージで、**読み出し（egress）が無料**＝この用途と相性が良く、無料枠（10GB）で足ります。
> コードはS3互換なので Backblaze B2 / AWS S3 でも `S3_ENDPOINT` を変えるだけで使えます。

### 手順
1. **Cloudflare** に登録 → **R2** → バケットを作成（例 `transcriber-uploads`）
2. **R2 APIトークン**（Object Read & Write）を発行 → `Access Key ID` と `Secret Access Key` を控える。
   画面の「Account ID」からエンドポイント `https://<アカウントID>.r2.cloudflarestorage.com`
3. バケットの **CORSポリシー** を設定（これが無いとブラウザから上げられません）:
   - Allowed origins: 公開URL（`https://xxx.onrender.com`）と `http://localhost:8000`
   - Allowed methods: `PUT`, `GET`
   - Allowed headers: `*`
   - **Expose headers: `ETag`**（分割アップロードに必須）
4. （推奨）バケットの **オブジェクトライフサイクル** で「未完了の分割アップロードを1日で中断」「オブジェクトを1日で削除」を設定（消し忘れ防止の安全網）
5. 環境変数を設定（Render ダッシュボード、ローカルなら `.env`）:
   - `S3_ENDPOINT` … `https://<アカウントID>.r2.cloudflarestorage.com`
   - `S3_BUCKET` … バケット名
   - `S3_ACCESS_KEY_ID` / `S3_SECRET_ACCESS_KEY` … 控えた値
   - `S3_REGION` … `auto`

設定後、`DIRECT_UPLOAD_MAX_MB`（既定200MB）より大きいファイルは自動でこの直アップロード経路を使います。
処理が終わるとアップロードした動画は自動削除されます。

## 語彙パック（固有名詞の表記補正・任意）

報道分野などの**固有名詞リスト**を選ぶと、その語を Whisper に教えて人名・専門用語の
表記精度を上げられます。ファイル投入後の確認画面で言語ボタンの下に「語彙パック」欄が出ます。
**既定は「選択しない」**（語彙補正なし）で、選ばなくても通常どおり文字起こしできます。

- 語彙の定義は **`vocab_packs.json`**（リポジトリ直下）。言語ごと（`ja` / `en`）に
  パックを定義します。選んだパックの語を Whisper の `prompt` に注入します。
- Whisper の `prompt` は**224トークン上限**（日本語=概算200字 / 英語=概算800字）。
  超える語数は自動で先頭から詰めて打ち切ります（`app/vocab.py` のトークン上限ガード。
  テスト: `python scripts/test_vocab_guard.py`）。**リクエスト数は増えません**（無料枠は不変）。
- **日本語パックの中身は時事用語**（要人名・役職など）です。**2026年上半期時点の想定**のため、
  要人交代・用語の流行に合わせて **`vocab_packs.json` を定期更新**してください。
- ⚠️ 日本語パックは UTF-8 の `vocab_packs.json` で管理します（文字化けに注意）。

## 文字起こしの校正（お手元のAIで）

無料運用を最優先しているため、固有名詞・専門用語・聞き取りにくい箇所は誤りが残ります。
仕上げは **ChatGPT / Claude / Gemini などに貼り付けて校正**するのがおすすめです。
**使い方ページ（`/help`）に校正用プロンプトのひな形**を載せてあり、ワンクリックでコピーできます。

> 以前は Groq の校正LLMで自動補正する「文章を整える」機能を内蔵していましたが、
> 効果が安定せず処理時間もかかるため**廃止**し、外部AIでの校正に一本化しました。

## 料金の目安（Groq）

- 無料枠：**1日2,000リクエスト / 音声 約2時間ぶん/時** ＝ 通常利用ならほぼ¥0
- 有料化しても `whisper-large-v3-turbo` で **約$0.04（≒¥6）/時間** と激安

## 設定（.env）

| 変数 | 説明 | 既定 |
|------|------|------|
| `GROQ_API_KEY` | GroqのAPIキー（必須） | （なし） |
| `APP_PASSWORD` | ログインの合言葉（必須） | `change-me` |
| `APP_PASSWORDS` | 複数の合言葉をカンマ区切りで許可 | （なし） |
| `SECRET_KEY` | セッション署名鍵（公開時は必ず設定） | 起動毎ランダム |
| `GROQ_MODEL` | `whisper-large-v3`（精度） / `-turbo`（高速） | `whisper-large-v3` |
| `DEFAULT_LANGUAGE` | `ja` / `en` / 空欄=自動 | `ja` |
| `MAX_UPLOAD_MB` | サーバー経由アップロードの上限 | `300` |
| `CHUNK_SECONDS` | 分割の長さ（秒） | `600` |
| `S3_ENDPOINT` ほか | 大容量動画むけ R2 直アップロード（上記「大容量動画」節） | （なし=無効） |
| `STORAGE_MAX_UPLOAD_MB` | 直アップロードの上限（R2有効時） | `3000` |
| `DIRECT_UPLOAD_MAX_MB` | これ以下は従来のサーバー経由で送る閾値 | `200` |

## 困ったとき

- **「合言葉が違います」** → `.env` の `APP_PASSWORD` と入力を確認
- **「GROQ_API_KEY が設定されていません」** → `.env` にキーを入れて起動し直す
- **動画で「音声トラックが見つかりません」** → その動画に音声が含まれているか確認
- **文字起こしが途中で止まる** → 無料枠の制限に達した可能性。少し時間をおいて再実行（自動で待機・再試行もします）
